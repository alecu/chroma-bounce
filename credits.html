Small machines.
A lot of good work.

Chroma Bounce is alecu’s Atmosphere experiment: an original pixel font, a bouncing credits scroller and a shared original AY soundtrack. The melody and arrangement are original, inspired by the energy of C64-era game music.

Oric Atmos browser player

Powered by Phosphoric, by bmarty and contributors, at revision 675cb06e02cf7c684377c5ae592dca7995d22097. The complete CPU, ULA, VIA and AY run in WebAssembly. The emulator core is unmodified; its browser wrapper boots the native TAP using an original reset/interrupt shim. No commercial Atmos BASIC ROM is included.

  • Phosphoric license — EUPL 1.2, with original notices
  • Matching Phosphoric source archive
  • Build flags and original boot shim

ZX Spectrum browser player

Powered by JSSpeccy 3.2, by Matt Westcott (gasman) and contributors. Its cycle-accurate WebAssembly core renders the scanline color effects and plays AY sound. The emulator JavaScript and WebAssembly come from the official v3.2 release. Its ROM slots contain zero-filled placeholders: the demo runs directly from its self-contained 128K snapshot, without Spectrum BASIC ROMs.

  • JSSpeccy license — GPL 3
  • Bundled JavaScript dependency notices
  • Matching JSSpeccy 3.2 source archive

Single-scanline Spectrum colors

The native Spectrum demo uses BIFROST*2 by Einar Saukas, based on the 20-column 8×1 multicolor method suggested by Matt Westcott (gasman). The z88dk adaptation is by aralbrec. It rewrites attributes in time with the display beam. The related NIRVANA+ technique provides 8×2 colors across a wider area; this demo uses BIFROST*2 to keep its single-scanline stripes.

  • BIFROST*2 license, instructions and full credits
  • Upstream engine source and attribution

Downloads and recordings

The downloads are the actual native builds, including Atmos TAP, Microdisc DSK, Cumana Reborn HFE/USB package, and Spectrum TAP/Z80 snapshot. Raw binaries require the documented load addresses. The optional videos are captures of the native demos, separate from the live emulators. Real-hardware testing remains pending.
